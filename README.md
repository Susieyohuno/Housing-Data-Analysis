# Housing-Data-Analysis
This project explores housing price trends using Excel to analyze a dataset containing various attributes like area, price, furnishing status, and utilities. The objective is to identify patterns that impact pricing and help stakeholders make informed real estate decisions.

# 1.	Project Overview
The housing project analysis gives insight into various housing prices available and allow for decision making. Excel was used to analyze the dataset which contained key attributes such as the price, size, number of bedrooms and bathrooms, furnishings etc. The objective was to determine key factors contributing to the prices of houses for decision making.

# 2.	Objectives
•	Identify features that significantly affect house prices
•	With the use of an interactive dashboard, show pattens and trends observed for visualization

# 3.	Methodology
The following were applied in carrying out the assignment
•	**Data cleaning**: 
This was done mainly to check for empty cells, duplicates, misalignment, uniformed data types and standardized formatting
•	**Segmentation**: 
Due to the wide range of prices, data was grouped into 3 segments, high, medium and low
•	**Pivot tables and charts:**
Pivot tables were then created to show summaries of key features for easy assessment
•	**Dashboard creation**: Slicers and charts were used to build an interactive interphase in a dashboard.

# 4.	Key findings
The analysis reveals that the minimum price of a house was **1,750,000.00** and the maximum price was **13,300,000.00** with an average price being **4,767,740.19**. Segregating the data into high, medium and low categories highlighted the majority of houses fall within the low-price band showing affordability of those houses. Data also showed that 56 houses out of the total 254 in the low category were furnished. This indicated that as much as **22%** of the affordable houses are fully furnished which provided an added advantage.
